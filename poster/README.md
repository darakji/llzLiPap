# A0 conference poster — MACE potential for the Li/LLZO garnet interface

## Build

```sh
tectonic poster.tex      # or: lualatex poster.tex
```

Produces a single A0 portrait page (2383.94 x 3370.39 pt).

## Layout

Title -> key numbers -> **block 00 "Why DFT-FE"** as a full-width band -> two
columns (01 System, 02 Method, 03 Selection | 04 Accuracy, 05 Full comparison,
06 Scope & independent check) -> 07 Status, full width.

Schematics are native TikZ. The four data figures are vector PDFs in `figs/`,
regenerated by `make_figs.py`.

## Figures

`make_figs.py` builds `figs/*.pdf` from the project's real data:

| figure | source |
|---|---|
| `fig_latent.pdf`   | `it6_final/epoch_sweep/fps_figure_data.json` — PC1/PC2 of the L2-normalised 256-d MACE latents for the full 62,029-frame it5->it6 candidate pool, the 77-frame seed and the 31 FPS picks |
| `fig_coverage.pdf` | `it5_final/latent_extraction/fps_coverage_curve.csv` + `fps_summary.json` (d99 threshold) |
| `fig_error.pdf`    | 34-structure held-out error table |
| `fig_campaign.pdf` | per-round pool sizes from each round's `fps_summary.json` |

`fig_coverage.pdf` is generated but not currently placed in the poster — the
stopping criterion is quoted numerically inside block 02 instead, for space.

## Fill in before printing

`\author{[author list]}` and `\institute{[affiliation]}` are placeholders.

## Space

The layout is full: content ends at 1173 mm of 1174 mm usable. Adding a block
or enlarging a figure will push block 07 off the page, and tikzposter gives no
warning when that happens — check the PDF, not just the log.
